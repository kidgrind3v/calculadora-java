# Calculadora em Java

Calculadora de terminal feita em Java, com menu interativo.

## O que ela faz
- Soma, subtração, multiplicação e divisão
- Tabuada de qualquer número (de 1 a 10)
- Avisa quando tentam dividir por zero

## O que usei
- Métodos separados para cada operação
- Menu com while e switch
- Leitura de dados com Scanner

## Como rodar
Compile e execute o arquivo Main.java.
